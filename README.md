# Portfolio Website 🚀

Modern developer portfolio with 3D animations, dark theme, and responsive design built with React.

## 🚀 Features
- Animated hero section with typewriter effect
- 3D card animations and particle background
- Projects showcase with live demo links
- Skills section with progress bars
- Contact form
- Fully responsive — mobile & desktop
- Dark theme UI

## 🛠️ Tech Stack
- React
- CSS3 (custom animations)
- JavaScript

## ⚡ Quick Start
```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
