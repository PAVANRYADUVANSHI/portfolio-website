## ✨ Features

- 👋 **Hero Section** — Typewriter effect with animated roles
- 🌌 **Particle Background** — Dynamic floating particles
- 🃏 **3D Avatar Card** — Rotating orbit rings animation
- 💼 **Projects Showcase** — Featured + grid layout with live links
- 🛠️ **Skills Section** — Progress bars with tech stack icons
- 📬 **Contact Form** — Working contact form with validation
- 🌙 **Dark Theme** — Sleek dark UI throughout
- 📱 **Fully Responsive** — Mobile, tablet & desktop
- ✨ **Smooth Animations** — CSS keyframes & transitions
- 🎨 **Gradient Accents** — Purple/green/blue color scheme

## ⚡ Quick Start

```bash
# Clone the repo
git clone https://github.com/PAVANRYADUVANSHI/portfolio-website.git
cd portfolio-website

# Install dependencies
npm install

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
